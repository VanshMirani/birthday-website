# 🎂 Birthday Surprise Website

An interactive and personalized birthday celebration website designed to create a memorable digital birthday experience. The website takes users through a series of engaging screens including a countdown, celebration animations, special messages, memories, and a final birthday wish.

## ✨ Features

* 🎉 Interactive birthday experience
* ⏳ Animated countdown sequence
* 🎂 Birthday cake celebration screen
* 💌 Personalized message and notes section
* 📸 Flashback memories section
* 🎊 Final birthday celebration page
* 📱 Responsive design for desktop and mobile devices
* 🎨 Modern and attractive user interface

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript

## 🚀 How to Run the Project

1. Clone the repository

```bash
git clone https://github.com/VanshMirani/birthday-website.git
```

2. Open the project folder

```bash
cd birthday-website
```

3. Open `index.html` in your browser

OR

Use VS Code Live Server extension for a better experience.

## 🎯 Purpose of the Project

The objective of this project is to create a unique and interactive way of wishing someone on their birthday through a personalized web experience. Instead of a traditional greeting, the website presents a journey filled with animations, memories, and special messages.
